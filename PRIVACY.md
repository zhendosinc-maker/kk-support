# Privacy Policy

KartoshkaSupport is a customized build of the open-source RustDesk remote desktop client.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

## Data Collection

KartoshkaSupport does not collect, store, or transmit any personal data, telemetry, or usage statistics to external servers.

## Network Connections

The application connects only to the self-hosted rendezvous and relay server configured at build time (`rustdesk.zhendosinc.ru`). No data is sent to third-party services.

## Third-Party Components

This project is based on [RustDesk](https://github.com/rustdesk/rustdesk) (AGPL-3.0). Please refer to the [RustDesk privacy policy](https://rustdesk.com/privacy/) for details on the underlying software.

## Contact

If you have questions about this privacy policy, please open an issue on the [GitHub repository](https://github.com/zhendosinc-maker/kk-support).
